# Ταρωτάκι — tarotaki.gr

Αστρολογική web app στα ελληνικά. Mobile-first, χωρίς build step, χωρίς
εξαρτήσεις. Ανεβαίνει όπως είναι σε οποιοδήποτε hosting.

```bash
python -m http.server 8000     # http://localhost:8000
```

## Πόσο «ακριβές» είναι

Δύο διαφορετικά πράγματα, και αξίζει να μη μπερδεύονται:

**Η αστρονομία είναι πραγματική και επαληθευμένη.** Το `ephemeris.js`
υπολογίζει θέσεις με:

| Σώμα | Μέθοδος | Ακρίβεια |
|---|---|---|
| Ήλιος | Meeus, χαμηλής ακρίβειας | ~0,01° |
| Σελήνη | Meeus κεφ. 47, 19 κύριοι όροι | ~0,02° |
| Πλανήτες | JPL στοιχεία Kepler (1800–2050) | ~1–2′ |

Επαληθεύτηκε με φυσικά αναλλοίωτα, όχι με «φαίνεται σωστό»:

- Ισημερίες και ηλιοστάσια 2026 με απόκλιση **< 0,04°**
- Μέγιστη αποχή Ερμή **28,13°** και Αφροδίτης **47,23°** — τα πραγματικά
  φυσικά όρια. Αν η γεωκεντρική μετατροπή ήταν λάθος, θα ξέφευγαν αμέσως.
- Ποσοστά αναδρομής σε 8 έτη: Ερμής 18,9%, Αφροδίτη 7,2%, Άρης 10,2%,
  Δίας 28,6%, Κρόνος 38,1% — όλα μέσα στις πραγματικές τιμές
- Ανάδρομη κίνηση ανιχνεύεται σωστά (☿ ℞ εμφανίζεται στον πίνακα)

**Οι ερμηνείες είναι παραδοσιακή αστρολογία**, όχι επιστημονική πρόβλεψη.
Αυτό γράφεται καθαρά στη σελίδα, στο πτυσσόμενο «Πώς βγαίνει αυτή η
πρόβλεψη».

### Πώς παράγεται η πρόβλεψη

Με τη μέθοδο που χρησιμοποιούν οι αστρολόγοι για ηλιακά ζώδια:

1. **Ηλιακοί οίκοι** — μετράμε από το ζώδιο του χρήστη. Ο οίκος όπου
   βρίσκεται η Σελήνη ορίζει τον τομέα της ημέρας (1ος = εαυτός,
   7ος = σχέσεις, 10ος = καριέρα…).
2. **Όψεις** — η στενότερη πραγματική όψη της Σελήνης (σύνοδος, εξάγωνο,
   τετράγωνο, τρίγωνο, αντίθεση) δίνει τον τόνο: εύκολος ή απαιτητικός.
3. **Κυβερνήτης** — ο πλανήτης του ζωδίου και η κατάστασή του.

Η Σελήνη κινείται ~13°/ημέρα και αλλάζει ζώδιο κάθε ~2,5 μέρες, οπότε
**η πρόβλεψη αλλάζει όντως κάθε μέρα** — δεν είναι ανακάτεμα φράσεων.
Ελεγμένο: σε 14 μέρες ένα ζώδιο περνά από 6 διαφορετικούς οίκους, και
την ίδια μέρα τα 12 ζώδια παίρνουν 12 διαφορετικούς οίκους.

Τα σκορ (Έρωτας / Δουλειά / Οικονομικά / Διάθεση) βγαίνουν κι αυτά από
τις πραγματικές όψεις — Αφροδίτη για τον έρωτα, Άρης και Κρόνος για τη
δουλειά, Δίας για τα οικονομικά — σταθμισμένα με το πόσο στενή είναι
κάθε όψη.

### Η γλώσσα του κειμένου

Κάθε πρόταση αντιστοιχεί σε ένα αστρονομικό γεγονός — δεν υπάρχει
«γέμισμα». Οι κανόνες που κρατάνε τα ελληνικά σωστά:

- **Πτώσεις πλανητών.** Κάθε σώμα έχει ονομαστική, αιτιατική και γενική
  (`ο Ήλιος` / `τον Ήλιο` / `του Ήλιου`). Χωρίς αυτό βγαίνει
  «σε τετράγωνο με **ο Ήλιος**».
- **Γένος.** Τα σώματα έχουν πεδίο `g`, ώστε να λέει «η Αφροδίτη είναι
  **ανάδρομη**» και «ο Κρόνος είναι **ανάδρομος**».
- **Συγχώνευση άρθρου.** Οι φράσεις οίκων και ζωδίων αποθηκεύονται σε
  αιτιατική (`τη δουλειά`, `τον Ζυγό`) και το «σε» μπαίνει ως πρόθεμα
  `'σ' + φράση` → `στη δουλειά`, `στον Ζυγό`. Δουλεύει και για τα έξι
  άρθρα χωρίς ειδικές περιπτώσεις.
- **Υποκείμενο.** Η σειρά των προτάσεων εναλλάσσεται ανά ημέρα· όταν η
  πρόταση της όψης μπαίνει πρώτη γράφεται «Η Σελήνη βρίσκεται…», αλλιώς
  «Βρίσκεται…», για να μην κρέμεται χωρίς αναφορά.
- **Ειδικές περιπτώσεις κυβερνήτη.** Στον Καρκίνο ο κυβερνήτης είναι η
  ίδια η Σελήνη (δεν επαναλαμβάνουμε τη θέση της), και όταν ο κυβερνήτης
  είναι αυτός που δοκιμάζει τη Σελήνη, το κείμενο το λέει ρητά.
- Η διατύπωση είναι «**που σε κυβερνά**», όχι «ο κυβερνήτης σου», γιατί
  η δεύτερη σπάει στο θηλυκό.

Ελεγμένο σε 12 ζώδια × 40 ημέρες = 480 κείμενα, χωρίς γραμματική
ασυμφωνία.

## Δωρεάν και Premium

| | Δωρεάν | Premium |
|---|---|---|
| Ωροσκόπιο — περίοδος | **Σήμερα, Αύριο, Εβδομαδιαία** | Μηνιαία, Ετήσιο |
| Ωροσκόπιο — κατηγορία | **Γενική εικόνα, Έρωτας, Εργασία, Τύχη** | — |
| **Συμβατότητα ζωδίων** | **Γενική εικόνα για όλα τα 144 ζευγάρια** | Αγάπη, οικειότητα, εμπιστοσύνη, επικοινωνία, εργασία, φιλία, δυνάμεις και προκλήσεις |
| Συναστρία | — | Πλήρης, με ημερομηνία και **ώρα γέννησης** και των δύο |
| Άλλα | Φάση σελήνης, κάρτα ταρώ | Big Three, όλες οι ρίψεις ταρώ, χωρίς διαφημίσεις |

Η γενική συμβατότητα ζωδίου-με-ζώδιο είναι **δωρεάν**. Οι αναλυτικές
ενότητες αγάπης, οικειότητας, εμπιστοσύνης, επικοινωνίας, εργασίας, φιλίας,
δυνάμεων και προκλήσεων ανοίγουν με Premium. Η **συναστρία** παραμένει
ξεχωριστή λειτουργία: χρειάζεται ακριβή ώρα και τόπο γέννησης και συγκρίνει
πλήρεις γενέθλιους χάρτες.

Τιμή: **10 €/μήνα** ή 79,99 €/έτος (6,67 €/μήνα, −33%). Στο
`main.js` → `PRICE_MONTHLY`, `PRICE_YEARLY`. Το ποσοστό έκπτωσης
υπολογίζεται μόνο του.

> **Δεν υπάρχει σύστημα πληρωμών.** Το gating είναι στο `page-horoscope.js`
> και είναι **μόνο οπτικό** με τον τοπικό adapter. Σε στατική σελίδα δεν
> γίνεται να κρυφτεί περιεχόμενο με ασφάλεια. Για αληθινό paywall θέλει
> λογαριασμούς, πάροχο πληρωμών (Stripe / Viva) και έλεγχο στον server.

## Λογαριασμοί

Ο λογαριασμός **δεν είναι υποχρεωτικός**. Ωροσκόπιο, συμβατότητα και ταρώ
διαβάζονται ελεύθερα. Χρειάζεται μόνο για να αποκτήσει κανείς και να
διαχειριστεί συνδρομή Premium.

> **Η τωρινή υλοποίηση είναι πρωτότυπο.** Ο τοπικός adapter αποθηκεύει τους
> λογαριασμούς στο `localStorage`. Αυτό **δεν είναι ασφαλής ταυτοποίηση**: ο
> χρήστης μπορεί να επεξεργαστεί τα δεδομένα του, ο λογαριασμός υπάρχει μόνο
> σε αυτή τη συσκευή, και δεν μπορεί να προστατέψει πληρωμένο περιεχόμενο.
> Η σελίδα το λέει καθαρά στον χρήστη.

Τι δουλεύει ήδη: εγγραφή με έλεγχο πεδίων, σύνδεση, αποσύνδεση, διαγραφή
λογαριασμού, κουμπί λογαριασμού στην κεφαλίδα όλων των σελίδων. Ο κωδικός
δεν γράφεται καθαρός — αποθηκεύεται salt + hash.

### 2η φάση: αληθινοί λογαριασμοί με επιβεβαίωση

Όλη η λογική είναι πίσω από adapter με σταθερές υπογραφές, οπότε δεν
ξαναγράφεται τίποτα. Στο `auth.js`:

```js
var ADAPTER = 'supabase';
var CONFIG = { supabaseUrl: 'https://xxxx.supabase.co', supabaseAnonKey: '…' };
```

και το SDK στη σελίδα. Το Supabase στέλνει μόνο του το email επιβεβαίωσης.
Χρειάζεται λογαριασμό Supabase — δεν τον φτιάχνω εγώ.

Το ίδιο ισχύει για τις πληρωμές: θέλει server που ελέγχει τη συνδρομή. Σε
στατική σελίδα το `IS_PREMIUM` είναι **μόνο οπτικό**.

## Κριτικές

Στο `reviews.js`, πίνακας `REAL`:

```js
{ user: 'Μαρία Κ.', stars: 5, date: '2026-08-18', el: { text: '…' } }
```

Νεότερες πρώτα, σήμα «Νέο» μέχρι 14 ημέρες, σχετικές ημερομηνίες, αυτόματη
εναλλαγή. **`DEMO_MODE = true`** δείχνει δείγματα διάταξης με ορατή
προειδοποίηση — βάλ' το `false` πριν ανέβει.

## Τι μένει πριν βγει στον αέρα

1. `DEMO_MODE = false` στο `reviews.js`
2. Φόρμες: `CONTACT_ENDPOINT` / `CONTACT_EMAIL` στο `main.js` (τώρα mailto)
3. Πληρωμές — δες παραπάνω
4. Στατικά νούμερα στις μακέτες κινητού της αρχικής (58%, 90%…)
5. Άρθρα χωρίς links
6. Οι μεγαλύτερες περίοδοι (εβδομάδα/μήνας/έτος) δίνουν σύνοψη αλλαγών
   ζωδίου· θέλουν πλουσιότερο κείμενο όταν ανοίξουν για συνδρομητές

## Σημειώσεις

- Mobile-first· breakpoints 560 / 768 / 960 / 1100px, στόχοι αφής ≥ 44px
- Καμία εξωτερική εικόνα — όλα CSS/SVG/Unicode
- Κείμενο χρηστών πάντα με `textContent`, ποτέ `innerHTML`
- Σέβεται το `prefers-reduced-motion`
- Ο listener του `languagechange` μπαίνει **πριν** το `T.init()` και στις
  δύο σελίδες· αν αντιστραφεί, δεν τρέχει το πρώτο render και μένουν άδεια
  τα select και τα πλέγματα
